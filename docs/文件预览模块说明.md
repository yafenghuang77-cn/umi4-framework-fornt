# 文件预览模块

菜单结构为 **文件管理 → 文件列表**，列表路由为 `/files/list`（部署后访问 `/framework/files/list`），原 `/files` 路由自动跳转到列表。列表页使用 ProTable 展示和查询文件，点击工具栏的“新增文件”打开 Ant Design Drawer，在抽屉内选择或拖入多个文件，可移除待添加的文件，点击“确认添加”后加入列表；取消或关闭抽屉会清空待添加文件。预览和文件链接表单使用 Ant Design Modal。

当前项目没有文件存储接口，因此列表仅保存在页面内存中，刷新或离开页面后清空。本地文件不会上传；URL 文件由浏览器直接获取，跨域服务需要配置 CORS。同源请求携带同源 Cookie，不向跨域地址附加业务 Token。

## 公共组件

其他模块直接使用 `@/components/FilePreview`，无需实现格式分流或加载逻辑。组件不包含业务弹窗，可以放在 Modal、Drawer、Card 或普通页面中。

```tsx
import FilePreview from '@/components/FilePreview';

// 浏览器文件选择器、拖拽或接口下载得到的 File 对象。
<FilePreview file={file} />;

// 文件 URL：组件自行加载、识别类型，并提供失败重试和下载。
<FilePreview url="https://example.com/report.pdf" />;

// 对没有扩展名的接口下载地址，可指定带扩展名的文件名。
<FilePreview url="/api/files/123/download" fileName="report.docx" />;
```

| 属性        | 类型     | 说明                                       |
| ----------- | -------- | ------------------------------------------ |
| `file`      | `File`   | 本地文件；与 `url` 同时传入时优先使用      |
| `url`       | `string` | HTTP / HTTPS 文件链接，也支持同源相对路径  |
| `fileName`  | `string` | URL 文件的可选名称，用于类型识别与下载命名 |
| `className` | `string` | 预览容器自定义样式                         |

更换文件或 URL 会重置预览状态；切换 URL、关闭预览或卸载组件会取消未完成的请求。图片和媒体的临时 Blob URL 会在卸载时释放。大型预览库按格式懒加载。

## 格式与边界

| 格式 | 格式处理与展示 | 分页方式 |
| --- | --- | --- |
| PDF | `react-pdf` 解析与渲染 | 按 PDF 页码，支持上一页、下一页、页码跳转 |
| DOCX | `docx-preview` 解析与渲染，隔离 iframe 展示 | 按插件识别的文档分页，支持上一页、下一页 |
| XLSX | `exceljs` 解析，Ant Design Table 展示 | 每页 20 行，上一页、下一页；切换工作表回到第一页 |
| CSV / TSV | 自定义分隔文本解析，Ant Design Table 展示 | 每页 20 行，上一页、下一页 |
| Markdown | `@uiw/react-md-editor` 的预览组件 | 连续阅读 |
| 文本 / 代码 | 浏览器原生文件读取，原文展示 | 连续阅读 |
| 图片 | Ant Design Image | 图片放大查看 |
| 音频 / 视频 | 浏览器原生播放器 | 播放进度控制 |
| ZIP | `jszip` 解包，Ant Design Table 展示条目 | 每页 10 个条目，上一页、下一页 |
| PPTX | `jszip` 解包，自定义 Open XML 文字提取 | 按幻灯片顺序，上一页、下一页 |
| 其他格式 | Ant Design Result 提示及下载入口 | 无预览分页 |

**实现核查：并非所有格式都使用专用预览插件。** PDF、DOCX、Markdown 使用预览插件；XLSX 和 ZIP 使用解析库配合 Ant Design 组件；CSV / TSV、普通文本及音视频使用自定义解析或浏览器原生能力；PPTX 的 JSZip 只负责解包，逐页文字由模块提取，不提供完整幻灯片渲染。

分页控件统一为内部 `PreviewPagination` 组件，使用 Ant Design Button、Space 和 InputNumber，显示当前页 / 总页数，首页禁用“上一页”，末页禁用“下一页”，无内容或加载时禁用翻页。PDF 的页码跳转保留。Word 只显示当前页，切换页码不会重新解析 DOCX；文本、Markdown、图片和音视频沿用各自的连续阅读或播放方式。

Word 的分页依据文档保存的手动分页符、编辑器保存的分页标记及分节位置；插件不按内容高度重新计算 Word 的排版页数。没有保存分页位置的长文档可能只有一个连续页面，精确排版需要下载查看。该边界来自 [docx-preview 的分页说明](https://github.com/VolodymyrBaydalka/docxjs#breaks)。

PPTX 不还原图片、图表、排版与动画。DOC / XLS / PPT 等旧版或其他 Office 格式需要转换为 DOCX / XLSX / PPTX / PDF。Excel 不执行公式计算、不完整还原样式或图表。媒体能否播放取决于浏览器支持的编码。密码保护的 PDF 提示下载后打开。

单个文件上限 50 MB；DOCX / XLSX / PPTX 预览上限 20 MB；文本及 CSV / TSV 上限 2 MB。表格最多预览 500 行、100 列，PPTX 最多 200 页，ZIP 最多展示 1000 个条目，超出时显示说明并可下载原文件。文本默认使用 UTF-8 编码。

Word 在隔离 iframe 内显示，禁止脚本并限制外部资源；Markdown 不执行原始 HTML。PDF Worker、CMap、字体和 WASM 由 `config/plugins/pdf-assets.ts` 从当前 `react-pdf` 的依赖生成到 `public/pdfjs/<版本>/`，开发和构建自动处理，发布时随项目产物一同部署，无需 CDN。生成目录已加入 Git 忽略。Nginx 需要将 Worker 的 `.mjs` 以 JavaScript MIME 返回，示例已补入[Nginx 部署说明](./Nginx部署说明.md)。

## 验证

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm test:e2e tests/e2e/files.spec.ts
pnpm build:uat
```

单元测试覆盖 CSV 边界、格式识别、ZIP 解压限制、URL 加载限制，以及组件换文件、URL 请求取消和失败重试。浏览器用例使用生成的 PDF、DOCX、XLSX、ZIP 和音视频样本，验证页面集成、URL 下载、损坏文件与小屏幕交互，并覆盖文档前后翻页、Word 分页标记、表格行分页、工作表切换时重置页码及 ZIP 条目翻页。
