# 代码规范文档

本项目采用蚂蚁前端团队的代码规范，确保代码质量和团队协作效率。

## TypeScript 配置

### 严格模式

项目启用了 TypeScript 的所有严格检查选项：

- `strict: true` - 启用所有严格类型检查
- `noImplicitAny: true` - 禁止隐式 any 类型
- `strictNullChecks: true` - 严格的 null 检查
- `strictFunctionTypes: true` - 严格的函数类型检查
- `strictBindCallApply: true` - 严格的 bind/call/apply 检查
- `noUnusedLocals: true` - 检查未使用的局部变量
- `noUnusedParameters: true` - 检查未使用的参数
- `noImplicitReturns: true` - 要求所有代码路径都有返回值
- `noFallthroughCasesInSwitch: true` - 禁止 switch 语句的贯穿
- `noUncheckedIndexedAccess: true` - 索引访问时添加 undefined 检查
- `noImplicitOverride: true` - 重写方法必须使用 override 关键字

### 路径别名

配置了 `@/*` 别名指向 `src/*` 目录：

```typescript
import { Component } from '@/components/Component';
```

## ESLint 配置

### 核心规则

**TypeScript 规则：**

- 推荐使用 `type` 导入：`import { type User } from './types'`
- 接口定义优先使用 `interface` 而非 `type`
- 禁止使用 `any`（警告级别），未使用的变量以 `_` 开头可忽略
- 必须处理 Promise（`no-floating-promises`）
- 优先使用可选链 `?.` 和空值合并 `??`

**React 规则：**

- 组件必须导出才能使用 React Fast Refresh
- 遵循 React Hooks 最新规范

**通用规则：**

- 禁止使用 `var`，优先使用 `const`
- 使用模板字符串而非字符串拼接
- 使用对象简写语法
- 必须使用 `===` 和 `!==`（null 除外）
- 所有条件语句必须使用花括号
- `console.log` 会产生警告（允许 `console.warn` 和 `console.error`）

### 文件特殊规则

**配置文件**（`*.config.ts`）：
- 不启用类型检查规则
- 允许使用 `console`

**测试文件**（`*.test.tsx`、`tests/**/*`）：
- 允许使用 `any` 类型
- 允许不安全的类型操作
- 允许使用 `console`

### 代码示例

**推荐写法：**

```typescript
// ✅ 使用 type 导入
import { type FC } from 'react';

// ✅ 使用 interface 定义对象类型
interface User {
  id: number;
  name: string;
  email?: string;
}

// ✅ 使用可选链和空值合并
const userName = user?.profile?.name ?? 'Anonymous';

// ✅ 使用 const 和箭头函数
const fetchUser = async (id: number): Promise<User> => {
  const response = await fetch(`/api/users/${id}`);
  return response.json();
};

// ✅ 正确处理 Promise
void fetchUser(1).then((user) => {
  console.warn('User loaded:', user);
});

// ✅ 数组索引访问会自动包含 undefined 类型
const items: string[] = [];
const first = items[0]; // string | undefined
```

**不推荐写法：**

```typescript
// ❌ 不使用 var
var count = 0;

// ❌ 不使用 any（除非必要）
function process(data: any) {}

// ❌ 不使用 == 或 !=
if (value == null) {}

// ❌ 未处理的 Promise
fetchUser(1); // 会报错

// ❌ 字符串拼接
const message = 'Hello, ' + name;

// ❌ 不使用 console.log（会警告）
console.log('Debug info');
```

## 最佳实践

1. **类型优先**：充分利用 TypeScript 的类型系统，避免使用 `any`
2. **异步处理**：所有 Promise 必须被正确处理（await 或 .catch）
3. **代码简洁**：使用现代 JavaScript 特性（可选链、空值合并、解构等）
4. **组件设计**：React 组件保持简单、可复用
5. **错误处理**：使用 `console.error` 而非 `console.log` 记录错误
6. **命名规范**：
   - 组件使用 PascalCase
   - 函数和变量使用 camelCase
   - 常量使用 UPPER_SNAKE_CASE
   - 私有变量/未使用变量以 `_` 开头
